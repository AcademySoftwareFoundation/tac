  - Commercial Products using OpenAPV
    - Galaxy S26 Ultra/Galaxy Z Fold 8/Vivo X300 Ultra

    - DaVinci Resolve 20.2+/Samsung Gallery/LumaFusion/CapCut
    - mpv/PotPlayer
    - ffmpeg has their own implementation, need to check conformance
  - Key Achievements in last year
    - v0.2.0.4 (Sept 25,2025) -> v1.1.1.0 (Sept 15, 2026)
      - Support fo APV RAW encoding / decoding (16 bit, 4 channel video)
        - Encoder does not support Bayer image format for input
        - Piecewise linear compressing/expanding is supported by the encoder and decoder
      - Introduction of API sets 1 including support for Tiled Mipmap Video use case for Unreal Engine
        - PBU-based encoding/decoding for flexible/fast processing
      - Introduction of new profiles relaxing the constraint on the number of tiles per frame
        - Previously limited to 64 tiles
        - Must consider requirements of hardware implementers
      - Performance improvement (SIMD optimization)
        - 1.1.2 is now 2x faster for decoding than 1.1.1.0
      - Security patches
        - Fixed 731 security vulnerabilities found by AI agent (internal project at Samsung to audit open source projects we are working on)
          - Software is now more secure / robust
  - Side Activities: ffmpeg
    - Vulkan accelerated encoding/decoding merged (9.0)
    - ffapv - FFmpeg plus up-to-date codec integrations available in [ffapv repo](https://github.com/openapv/ffapv)
      - If you want to use ffmpeg with integrated APV until everything merged into official ffmpeg
  - Next Steps
    - Ready to be an incubation project by next year
    - Since we've reached a 1.0 status, everything is stable
    - Sustained interest and contribution, we may propose to move to incubation stage
    - Started looking at OpenSSD badge, working on required improvements
